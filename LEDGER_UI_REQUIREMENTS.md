## Architecture Context

The SunarKhata frontend is a **single-page Vanilla JavaScript application** using:

- **Hash router** (`src/router.js`) — routes like `#/account/:id`, `#/mutual/:id`
- **Page renderers** — functions like `renderIndividualAccount(container, accountId)` that receive a DOM container and produce the full page HTML
- **Service layer** — `individual.service.js` and `mutual.service.js` handle all data persistence and business logic
- **Position engine** — `src/utils/position-engine.js` provides all signed-balance calculations, zero-crossing, state derivation, and dynamic action labels
- **Transaction overlay** — `src/pages/transaction.js` renders modal overlays for all transaction types (increase, decrease, conversion, rate booking)

There is **no component framework** (no React, Vue, Svelte). All rendering is imperative: build an HTML string, set `container.innerHTML`, then attach event listeners.

## Required Rupee UI Files / Code

### FILE 1: Individual Account — Rupee Ledger Section

**Purpose**: The Rupee half of the individual account dual-ledger view. Replaces the current placeholder in `individual-account.js`.

**Location in page**: Second `<section>` inside the `<!-- LEDGER SPLIT/TABS -->` container, shown when `activeTab === 1` (mobile) or always visible (desktop side-by-side).

**Required visible fields**:
- Rupee balance (absolute value, formatted with Indian grouping: `₹10,00,000`)
- Position badge: `RECEIVABLE` / `PAYABLE` / `ZERO`
- Position sub-text: `Lena Hai` / `Dena Hai` / `Neutral`

**Exact three Rupee actions** (dynamic labels):

| # | If RECEIVABLE | If PAYABLE | If ZERO |
|---|--------------|------------|---------|
| 1 | INCREASE RECEIVABLE | INCREASE PAYABLE | CREATE RECEIVABLE |
| 2 | DECREASE RECEIVABLE | DECREASE PAYABLE | CREATE PAYABLE |
| 3 | RUPEE TO METAL | RUPEE TO METAL | RUPEE TO METAL |

**Action opcodes** (passed as `data-type` on buttons):

| Action | Opcode (from position engine) |
|--------|-------------------------------|
| Action 1 | `rupeeActions.action1Op` (e.g., `increase_receivable`) |
| Action 2 | `rupeeActions.action2Op` (e.g., `decrease_receivable`) |
| Action 3 | `convert_rupee_to_metal` (fixed string) |

These opcodes are already generated by:
```javascript
import { getActionLabels } from '../utils/position-engine.js';
const rupeeActions = getActionLabels(rupeePos);
// rupeeActions.action1Op, rupeeActions.action1Label
// rupeeActions.action2Op, rupeeActions.action2Label
```

**Required button attributes**:
```html
<button class="act-btn" data-type="${rupeeActions.action1Op}" data-ledger="rupee">
```

**Required modal inputs** (handled by existing `transaction.js`):
- Direct increase/decrease: Amount in ₹, optional Mention
- Rupee to Metal: Rupee Amount, Gold Rate (per 10g), optional Mention

**Required UI states**:
- Default: Shows balance + actions + transaction history
- Zero balance: Shows `₹0` with `ZERO` badge, actions become CREATE RECEIVABLE / CREATE PAYABLE
- Transaction history empty: "No rupee transactions yet."

**Backend service function**: 
```javascript
import { addTransaction } from '../services/individual.service.js';

// Direct Rupee transaction
addTransaction(accountId, {
  section: 'rupee',
  action: rupeeActions.action1Op,  // e.g., 'increase_receivable'
  amount: rupeeAmount,             // number, in ₹
  mention: mentionText             // string, optional
});

// Rupee to Metal conversion
addTransaction(accountId, {
  section: 'rupee',
  action: 'convert_rupee_to_metal',
  amount: rupeeAmount,                    // ₹ amount being converted
  rate: goldRatePer10g,                   // number
  sourceOperation: rupeeActions.action2Op, // e.g., 'decrease_receivable'
  mention: mentionText
});
```

**Return/Result state**: After `addTransaction`, call `getAccount(accountId)` to get updated account with:
- `account.rupee_balance` — absolute value
- `account.rupee_class` — `'receivable'` | `'payable'`
- `account.transactions` — array with the new transaction appended

**Transaction history row data**:
```javascript
const txn = {
  id: 'uuid',
  section: 'rupee',
  action: 'increase_receivable',
  amount: 50000,
  mention: 'Invoice 124',
  created_at: '2026-07-04T...',
  prev_balance: 100000,
  result_balance: 150000,
  prev_class: 'receivable',
  result_class: 'receivable',
  // For conversions:
  rate: 72000,
  result_grams: 6.944,
  sourceOperation: 'decrease_receivable',
  sourceDelta: -50000,
  targetDelta: 6.944
};
```

## Available Template Variables

When authoring the Rupee section HTML, these JavaScript variables are available in scope:

```javascript
// Balances
rupeeBal        // number — absolute rupee balance
rupeePos        // string — 'receivable' | 'payable'
rupeePosLabel   // string — 'RECEIVABLE' | 'PAYABLE' | 'ZERO'
rupeeBadgeColor // string — CSS classes for badge coloring

// Actions (from position engine)
rupeeActions.action1Op    // string — e.g., 'increase_receivable'
rupeeActions.action1Label // string — e.g., 'Increase Receivable'
rupeeActions.action2Op    // string — e.g., 'decrease_receivable'
rupeeActions.action2Label // string — e.g., 'Decrease Receivable'

// Formatting helpers
fmtR(rupeeBal)  // string — Indian-formatted number (no ₹ symbol)

// Transaction history
getTransactionHTML('rupee')  // string — rendered HTML of rupee transactions

// Tab state
activeTab  // number — 0 = Metal, 1 = Rupee
```
